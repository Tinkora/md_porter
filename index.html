What it does

A small, auditable workflow for private notes and developer documentation.

Bounded GFM subset

Tables, task lists, strikethrough, footnotes, autolinks, and fenced code blocks.

Split preview

Write on the left and review safe HTML on the right. Rust and WASM run locally.

Offline HTML export

Download one HTML file with embedded CSS. No JavaScript or remote assets are included.

YAML frontmatter

Inspect simple key-value metadata at the start of a Markdown document.

Language classes

Fenced code language classes are preserved for downstream tools; highlighting is not bundled.

Privacy first

All content stays in the browser. There is no server, upload path, or tracking.

Run locally

You need the Rust toolchain and wasm-pack. The browser page is the product.

1. Clone and build

# Clone the repository
git clone https://github.com/Tinkora/md_porter.git
cd md_porter

# Build the WebAssembly package
wasm-pack build --target web crates/md_porter_web

2. Start a local server

cp crates/md_porter_web/pkg/* crates/md_porter_web/static/pkg/
cd crates/md_porter_web/static
python3 -m http.server 8080

# Open http://localhost:8080 in a browser
